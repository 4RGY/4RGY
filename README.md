### Data work

- **[ihsg-idx-analytics](https://github.com/4RGY/ihsg-idx-analytics)**, risk and return for 22 IDX stocks plus IHSG. Ten metrics, four charts, monthly seasonality. The finding worth reading: 17 of 22 stocks had negative Sharpe, and the winners (ADRO, PTBA) only had 0.36 correlation to the index.
- **[cuaca-indonesia](https://github.com/4RGY/cuaca-indonesia)**, BMKG forecast for 19 cities, 375 slots, early warnings for rain above 20 mm per 3 hours. The API sits behind Cloudflare, so the fetch layer uses `curl_cffi` with Chrome TLS impersonation.
- **[gempa-indonesia](https://github.com/4RGY/gempa-indonesia)**, BMKG earthquake catalogue with Gutenberg-Richter b-value (Aki-Utsu) and an energy balance in joules and TNT. Its README snapshot rewrites itself on every run.

All three are Python, recomputed on each run, tested offline, and refreshed by GitHub Actions. Never a hardcoded number.
